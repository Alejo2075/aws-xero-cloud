# RFCs

Open an RFC (a markdown file `NNNN-title.md` in this directory) before introducing a backward-incompatible contract, mandatory
external infrastructure, or a new category of AWS event integration (for example EventBridge, API Gateway or Step Functions
ingress). Decisions that fit the topics listed in `CLAUDE.md` §17 are recorded as ADRs in `docs/adr/` instead.

An RFC states the problem, the proposal, the AWS permissions and cost impact, security and failure semantics (including
duplicate delivery and unknown outcomes), compatibility, and what is explicitly out of scope.
